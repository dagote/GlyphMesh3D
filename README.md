# GlyphMesh3D

A Unity package for 3D glyph mesh generation and manipulation.

## Installation

### Install via Git URL

You can install this package directly from GitHub using Unity's Package Manager:

1. Open Unity Editor
2. Open the Package Manager window (Window > Package Manager)
3. Click the `+` button in the top-left corner
4. Select "Add package from git URL..."
5. Enter the following URL:
   ```
   https://github.com/CCoxLanternPines/GlyphMesh3D.git
   ```
6. Click "Add"

### Install a Specific Branch

To install a specific branch, append `#branch-name` to the URL:
```
https://github.com/CCoxLanternPines/GlyphMesh3D.git#copilot/setup-accessible-git-link
```

### Install a Specific Version

To install a specific version tag, append `#v1.0.0` (or the version number) to the URL:
```
https://github.com/CCoxLanternPines/GlyphMesh3D.git#v1.0.0
```

### Install via manifest.json

Alternatively, you can add the package to your project's `Packages/manifest.json` file:

```json
{
  "dependencies": {
    "com.lanternpines.glyphmesh3d": "https://github.com/CCoxLanternPines/GlyphMesh3D.git"
  }
}
```

## Requirements

- Unity 2020.3 or later
